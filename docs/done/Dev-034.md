# Dev-034: HUD opacity and scale

[Interface] [Upgrade]

## Goal

Make the HUD and action menus fully opaque and 150% bigger, so they read at a glance.

## Work

- [x] Set the shared interface modulation alpha to `1.0` in `GameHud` (HUD root and action menus).
- [x] Add `GameHud.UiScale` (`1.5`) with `S`/`V` helpers and route every panel size, position, font
      size, separation and style margin through them, so the layout keeps its original numbers.
- [x] Match the scale in `GeneratorPanel` (`S`/`V` with `1.5`) and `ActionMenuOverlay` (`S`/`Sc`/`V`),
      which are separate controls, and scale `CompassOverlay` to `120` px.
- [x] Raise visibility: brighter `TextColor`/`DimColor`, darker panel frames with a stronger border,
      thicker compass lines and a more opaque compass background.
- [x] Move the FPS counter to the bottom-right corner and keep the compass between the clock and
      `CARRY`, so the 150% panels do not overlap.
- [x] Run `npm run check` and inspect a fresh 1280×720 capture.
- [x] Update the Notion Work Report and move this doc to `docs/done/` when accepted.

## TL;DR

The HUD, dialogs and action menus render at 100% opacity and 150% scale, with stronger contrast; a
single `UiScale` constant drives every layout number.
