# Dev-035: Interface typeface legibility

[Interface] [Upgrade]

## Goal

Replace the wide, geometric Montserrat with a UI face that reads better at the HUD's small sizes,
so labels, the feed and the menus stay legible.

## Work

- [x] Add `Inter-VariableFont_opsz_wght.ttf` (SIL OFL) to `game/assets/fonts/` and import it.
- [x] Point `GameHud` at the Inter font instead of Montserrat, keeping the shared theme and every
      control's font-size override unchanged.
- [x] Remove the unused Montserrat font and its `.import` sidecar.
- [x] Run `npm run check` and inspect a capture of the HUD at 1280×720.
- [x] Update the Notion Work Report and move this doc to `docs/done/` when accepted.

## TL;DR

The Godot HUD, generator forms and action menus use Inter, a taller-x UI face, instead of Montserrat.
