# Dev-038: Dirt texture (BitCanvas)

[Art pipeline] [Tooling]

The user asked for a pure dirt texture generated with BitCanvas. BitCanvas had no `dirt`
material: dirt existed only as patches inside grass tiles (`dirtPatch` in `BitCanvas/terrain.js`)
and as the grass cliff strata, both hard-coded to `DIRT_COLORS`. This doc adds a `dirt` terrain
material to BitCanvas and generates its two sheets with the standard defaults. Wiring the sheets
into the game renderer is out of scope until a world material named `dirt` exists.

Reference: `docs/done/Dev-010.md` (how a BitCanvas material is added, generic side path, defaults).

## 1. Decisions to approve

| Topic | Decision | Why |
|---|---|---|
| BitCanvas key | New terrain material `dirt`, listed right after `grass` | It is natural ground, the sibling of grass; the same key any future world material would use |
| Game files | `floor/dirt_x4.png` (256×32) and `floor/dirt_side_x4.png` (128×32) | `floor/` already holds the non-grass ground surfaces and `gamesync.js` already accepts it; a new folder buys nothing until the game consumes the sheets |
| Look | Packed earth on the `DIRT_COLORS` tones: broad moisture blotches, fine crumb noise, sparse dry-crumb speckle and dark pores, one rare pebble chip. No grass, no joints | The default ramp brackets the soil tones the grass patches and cliff strata already paint, so dirt tiles, worn grass patches and cliff faces stay one world |
| Sides | Reuse the generic side path (the one concrete and asphalt use) | A slab edge of earth is the same soil; no special code |
| Palettes | Four earth ramps [Sec. 2.2]: Loam (defaults to the `DIRT_COLORS` tone), Peat, Clay, Dust | Same four-slot structure as every material |
| Density and dirt | Not shown for dirt (they stay `grass-only`) | Same as the other non-grass materials |
| Default sheets | Generated headlessly with seed `A17F3C`, first palette (`Loam`), brightness 58, density 6 | Reproducible; the user can regenerate with any seed through "Send to game" |

## 2. What changes

### 2.1 `bitcanvas` (v0.0.7 → v0.0.8)

`BitCanvas/core.js`:

- `materialPalettes.dirt` [Sec. 2.2].
- `GAME_SHEETS.dirt = { folder: 'floor', variants: 'dirt_x4.png', sides: 'dirt_side_x4.png' }`.

`BitCanvas/terrain.js`:

- `materialLevel`: a new `else if (material === 'dirt')` branch **before** the `brick` branch:

  ```js
  } else if (material === 'dirt') {
    // Packed earth on the same tones as the grass patches and the cliff strata:
    // broad moisture blotches, fine crumb noise, and sparse light speckle.
    const broad = isoNoise(x + 0.5, y + 0.5, 4, 4, seed);
    const fine = isoNoise(x + 0.5, y + 0.5, 15, 11, seed ^ 0x2545f491);
    const grain = materialCellHash(x, y, seed ^ 0x3c6ef372) % 100;
    level = 3.4 + (broad - 0.5) * 1.2 + (fine - 0.5) * 0.8 + brightness;
    if (grain < 20) level += 0.9;        // dry crumb, dirtPatch's light tone
    else if (grain < 26) level -= 1.2;   // dark pore
    else if (grain === 99) level += 2.4; // rare pebble chip
  }
  ```

  Same structure as asphalt: `isoNoise` already wraps so the tile is seamless; the per-pixel hash
  has no structure to break at a seam.

`BitCanvas/app.js`:

- `updateMaterialControls` `materials` table: `dirt: { title: 'Dirt texture', subtitle: 'Packed
  earth', corner: 'BARE GROUND', description: 'Packed earth with moisture blotches, crumb speckle
  and scattered pebbles.' }`.
- `randomMaterialPalette`: dirt hue `[20, 40]`, saturation `[25, 50]`, default lightness span.

`BitCanvas/index.html`: one row after the Grass button, same markup as its neighbours:
`id="dirt-material"`, `data-material="dirt"`, icon `▒`, `<b>Dirt</b>`,
`<small class="meta">floor/dirt_x4</small>`.

`BitCanvas/sides.js` and `BitCanvas/gamesync.js`: no change (dirt takes the generic side branch;
`floor/` is already an accepted folder).

### 2.2 Dirt palettes

Eight steps, darkest to brightest. The `meadow` ramp brackets `DIRT_COLORS`
(`[146,108,66] [116,83,50] [88,62,38] [62,44,28]`): most pixels land on `ramp[3..4]`
(`[101,73,44]`, `[118,85,52]`, average of the default sheet (110, 80, 48)), dry crumbs on
`ramp[5..6]`, pores on `ramp[2]`, pebble chips on `ramp[6]`.

| Key | Name | Detail | Ramp |

### 2.3 Sheets (`game/assets/sprites/floor/`)

`floor/dirt_x4.png` (256×32) and `floor/dirt_side_x4.png` (128×32), generated from the [Sec. 1]
defaults and committed. The render ran BitCanvas's own `core.js` + `terrain.js` + `sides.js` in a
Node `vm` sandbox with a canvas shim (the Dev-009/Dev-010 headless route); the same run proved the
seven pre-existing materials' sheets byte-identical before and after the edit, so the regression
in [Sec. 3] holds.

## 3. What must not break

- Grass, planks, cobblestone, concrete, asphalt, roofing and brick output stays byte-identical
  for the same inputs (the new branch sits before cobblestone's `else`; nothing else in the
  generation path changes). Verified by SHA-256 of a headless render before and after the edit.
- BitCanvas still opens from `file://` with no build; furniture tab untouched.
- The game renderer is not touched; no existing game asset is replaced.

## 4. Acceptance

1. Headless render at the defaults before and after the edit: all seven existing materials'
   sheet SHA-256 match.
2. BitCanvas lists Dirt after Grass; tiles, block and sides views render it; the four palettes
   show the [Sec. 2.2] names; `P` (random palette) yields an earthy brown ramp; `↑`/`↓` reach it.
3. The default sheet's average tone sits within a few points of `DIRT_COLORS[1]` (116, 83, 50),
   so dirt tiles read as the same earth as grass's dirt patches and cliff strata.
4. `floor/dirt_x4.png` is 256×32 and `floor/dirt_side_x4.png` is 128×32; the destination line
   reads `→ sprites/floor/ dirt_x4.png + dirt_side_x4.png`.

### Verification run 29/09/2026

  and after the edit: all fourteen sheet SHA-256 match. The committed roofing and brick sheets

  the atlas averages (110, 80, 48) with its top tones on `ramp[3..4]`, crumbs on `ramp[5]`, pores

## TL;DR

Adds a `dirt` material to BitCanvas (packed earth on the `DIRT_COLORS` tones, four palettes,
generic side path), lists it after Grass, and generates `floor/dirt_x4.png` and
`floor/dirt_side_x4.png` headlessly with the standard defaults. Bumps `bitcanvas` to v0.0.8.
All pre-existing materials' sheets stay byte-identical.
