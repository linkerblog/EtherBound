# Dev-028: Cliff traversal visibility

[Rendering] [Upgrade]

## Goal

Keep the controlled actor visible while it passes behind a natural grass cliff, without removing
the cliff or changing simulation state.

## Work

- [x] Hide a centered circular area of foreground terrain and structure faces at any camera depth,
  including 0.5 m grass steps, without retaining the old horizontal cut.
- [x] Enable the circle only while a body-height ray toward the camera finds terrain or a structure
  in the way, so a visible Niko is never cut.
- [x] Hide the cut surfaces completely instead of tinting them, keeping a narrow soft rim.
- [x] Clear tops and faces of every terrain material as one clean circular window around Niko, with
  the floor under his feet and props left intact, so no tile splits by material sheet or depth.
- [x] Add `X` to switch between the local player fade and a current-level view that clips terrain
  and structures above Niko's 3 m level band, useful while digging; retain `C` as the master toggle.
- [x] Anchor the fade to Niko's projected screen position, including the camera pitch and the
  render root's vertical scale; world Y alone displaced it down the cliff face.
- [x] Reuse the existing `C` cutaway toggle; local mode hides whatever covers Niko, while level mode
  clips overhead geometry and retains lower excavation.
- [x] Build, run `npm run check`, and import the shader headlessly.
- [x] Inspect x1/x2/x4 captures for the around-player cutout and current-level mode from isolated
  backups of the user's lab seed `375516263` (`spawn_bay=dig`); the original save was not modified.
- [x] Confirm `X` switches modes and `C` disables the selected mode during live movement along the
  tall cliff. User confirmed 27/09/2026.

## TL;DR

`X` switches between a wide circular cut that hides whatever covers Niko, on only while he is
actually hidden, and a current-level view that hides overhead terrain while keeping lower
excavation visible. `C` disables the selected mode.
