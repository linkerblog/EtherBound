# EtherBound

An endless isometric life sandbox: *Project Zomboid without zombies + RimWorld*, with an LLM
narrative layer on top. It is a remake of NikoStory. You play Niko Unit Zero, a bioengineered
combat unit from another dimension and the only Ether bearer, in a city of hybrids.

Nothing in the game is a scripted feature. Few generic primitives (matter, physics, time,
knowledge) combine into behavior nobody wrote, and the world reacts to what it *knows*, not to
what happened out of sight.

> **Status:** early development (phase 1). The world, movement, digging, objects and tile physics
> work; the narrative layer, NPC minds and knowledge propagation are still ahead. Windows is the
> supported development platform. Singleplayer, on a deterministic C# simulation with a Godot 4
> 3D orthographic client (`docs/done/Dev-025.md`); the earlier Python/web stack was retired at cut-over.

## Principles

- **The world engine is the only writer of state.** Everything else proposes; the engine
  validates, resolves and commits.
- **One action API.** The player, Agents and Extras act through the same ops.
- **Systems talk only through the event bus.**
- **LLMs propose, code decides.** Every LLM decision is logged as an event, so a run can be
  replayed from its seed.
- **Endless and replayable.** A seed plus the player's choices gives a different history each run.

The full design lives in [`docs/utils/VISION.md`](docs/utils/VISION.md).

## Stack

| Layer | Technology |
|---|---|
| Simulation | C# (.NET 10), one deterministic sim thread per run, `PyRandom` (bit-exact MT19937) |
| Persistence | SQLite via `Microsoft.Data.Sqlite`, same schema and migration numbers as phase 1 |
| Client | Godot 4.7.2 (.NET), 3D orthographic pixel-art camera, `Control` UI theme |
| Art | Own pixel art; textures and furniture are generated by BitCanvas and imported as meshes/sheets |

## Getting started

Requirements: the .NET 10 SDK, Node.js and npm (for the check scripts), and Godot 4.7.2 (.NET/mono
build) to run or export the client.

```text
npm run setup                          # enable the git hooks
dotnet build EtherBound.sln            # sim, host, tests, bench
"$GODOT_BIN" --path game               # run the client (GODOT_BIN points at the Godot 4.7.2 editor)
```

The client takes `--seed`, `--generator` (`test` or `lab`) and `--database` (defaults to the
user data dir) after `--`; the sim owns the save, so the same `data/etherbound.db` reopens across
runs. To open the sprite/furniture generator on its own, run `npm run bitcanvas`.

## Checks

```text
npm run check                 # versions, docs, sizes, BitCanvas, furniture export, sim, game
npm run check:fast            # versions (staged files), docs, sizes, BitCanvas syntax
npm run check:sim             # dotnet test sim/EtherBound.Sim.Tests
npm run check:game            # dotnet build game; headless Godot import when GODOT_BIN is set
```
