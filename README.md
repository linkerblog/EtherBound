# EtherBound

An endless isometric life sandbox: *Project Zomboid without zombies + RimWorld*, with an LLM
narrative layer on top. It is a remake of NikoStory. You play Niko Unit Zero, a bioengineered
combat unit from another dimension and the only Ether bearer, in a city of hybrids.

Nothing in the game is a scripted feature. Few generic primitives (matter, physics, time,
knowledge) combine into behavior nobody wrote, and the world reacts to what it *knows*, not to
what happened out of sight.

> **Status:** early development (phase 1). The world, movement, digging, objects and tile physics
> work; the narrative layer, NPC minds and knowledge propagation are still ahead. Windows is the
> supported development platform.

## Principles

- **The world engine is the only writer of state.** Everything else proposes; the engine
  validates, resolves and commits.
- **One action API.** The player, Agents and Extras act through the same ops.
- **Systems talk only through the event bus.**
- **LLMs propose, code decides.** Every LLM decision is logged as an event, so a run can be
  replayed from its seed.
- **Endless and replayable.** A seed plus the player's choices gives a different history each run.

The full design lives in [`docs/utils/VISION.md`](docs/utils/VISION.md).

## Stack

| Layer | Technology |
|---|---|
| Server | Python 3.14, FastAPI, WebSocket world streaming |
| Persistence | SQLite with SQLAlchemy and Alembic migrations |
| Client | Phaser 3 (isometric 2:1 world) + React overlay, TypeScript, Vite |
| Type contract | Pydantic models → OpenAPI → generated TypeScript types |
| Launcher | C# (.NET 10, Native AOT) dev launcher |
| Art | Own pixel art; textures and furniture are generated by BitCanvas |

## Repository layout

| Path | Contents |
|---|---|
| `server/` | Game server: world engine, ops, events, network, database, world generation |
| `web/` | Browser client: renderer, prediction, UI overlay |
| `launcher/` | `EtherBound.exe`, which runs the server and the web client together |
| `BitCanvas/` | Standalone seeded texture and furniture sprite generator (plain HTML/JS) |
| `src/sprites/` | Generated sprite sheets shared with the game |
| `docs/` | Vision, versions, style guide, plans in progress and pending decisions |

## Getting started

Requirements: Python 3.14 with [uv](https://docs.astral.sh/uv/), Node.js and npm, and the
.NET 10 SDK (with the VS Build Tools for the Native AOT link) for the launcher.

```text
npm run setup                 # enable the git hooks
cd server && uv sync          # server dependencies
cd web && npm install         # client dependencies
npm run launcher:build        # build EtherBound.exe (once, and after changing launcher/)
EtherBound.exe                # server with hot reload + web client
```

Logs go to `logs\`. `EtherBound.exe --no-reload` disables the restart on saved server sources,
and `EtherBound.exe --cleanup` kills leftovers from this checkout.

To open the sprite generator on its own, run `npm run bitcanvas`.

## Checks

```text
npm run check                 # versions, server, web, BitCanvas and launcher
npm run check:fast            # versions (staged files), Ruff, BitCanvas syntax
npm run check:visual          # Playwright isometric baselines (needs free ports)
```
