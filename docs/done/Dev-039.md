# Dev-039: Dirt terrain sheets in the game renderer

[Bugfix] [Rendering] [Art]

Register the generated dirt sheets for both `topsoil` and `dirt` in the Godot client. The first
completed dig exposes `topsoil`, while deeper digs later expose `dirt`; both now render with the
packed-earth tile until a dedicated topsoil sheet exists. Keep the existing stratum depths and
simulation behavior unchanged.

## 1. Changes

- Add `topsoil` and `dirt` to `WorldClient.Sheets`, using `floor/dirt_x4.png` and
  `floor/dirt_side_x4.png`.
- Document the material-key-to-sheet requirement in `CONTEXT.md` and `docs/utils/PITFALLS.md`.
- Bump `game.app` from v0.0.7 to v0.0.8.

## 2. Acceptance

1. `WorldClient` decodes the dirt sheets and associates them with both world material IDs.
2. The initial excavation renders a dirt tile because its exposed material is `topsoil`.
3. Repeated digging still follows the original `topsoil` → `dirt` → `rock` stratum depths.
4. `npm run check` passes.
