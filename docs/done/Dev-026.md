# Dev-026: Terrain depth

## Goal

Make gradual terrain elevation changes read clearly in the isometric view without changing world
geometry, movement, or simulation state.

## Work

- [x] Derive terrain-top lighting normals from neighboring ground heights; cap the slope cue so
  cliffs remain represented by their vertical faces.
- [x] Extend the height-shade range on horizontal surfaces so raised terraces separate tonally
  while preserving the existing exposed-side palette.
- [x] Focus directional shadow precision on the visible area and reduce detached contact shadows.
- [x] Build the game and run `npm run check` (189 simulation tests pass).
- [x] Rebuild, import the project headlessly with Godot 4.7.2 Mono, and inspect GPU captures at
  x1/x2/x4 after the supplied image showed the initial shading pass was too subtle.

## TL;DR

Terrain height changes gain stronger top-surface contrast, directional shading and more local,
grounded shadows without affecting simulation geometry.
